# Pivot Mockups

Pivot 产品的 UI 方案预览页面，纯静态 HTML，托管在 GitHub Pages 给团队成员浏览。

## 当前在做的方案

**AI 调度台 v2 · 弹出框设计** — 调度台点击事项后弹出上下文的几种形态对比。

入口：[index.html](./index.html)

主推：[scheduler-showcase.html](./scheduler-showcase.html)（集成 demo，5 种风格一页对比）

## 在线访问

启用 GitHub Pages 后，访问：

```
https://yezaiyong.github.io/pivot-mockups/
```

## 添加新 mockup

1. 复制 HTML 文件到本目录
2. 编辑 `index.html` 在合适分组加一张卡片
3. `git commit + push`，Pages 自动更新（约 1-2 分钟）
